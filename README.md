# AI-Powered Personal Portfolio

An interactive AI-powered personal portfolio designed to showcase my skills, projects, experience, and technical journey while demonstrating practical applications of Generative AI.

The portfolio combines a traditional developer portfolio with AI-powered features to create a more interactive and useful experience.

## Key Features

### 1. Personal AI Chatbot

An AI-powered chatbot that acts as a personal assistant for my portfolio.

It can answer questions related to:

- Technical skills
- Projects
- Education
- Experience
- Certifications
- AI/ML knowledge
- Data Analytics skills
- Professional background

The chatbot uses the portfolio information as context to provide relevant responses.

### 2. AI-Powered Job Description Matcher

The Job Description Matcher allows users to upload a Job Description in:

- PDF format
- DOCX format

The application extracts the text from the uploaded document and uses Generative AI to compare the requirements with my current profile.

It provides:

- Match Score
- Matching Skills
- Missing / Required Skills
- Strengths
- Recommendations
- Final Verdict

This feature demonstrates how AI can be applied to practical job-search and career-alignment use cases.
